# ChatGPT GitHub Demo

Небольшой тестовый проект, созданный ChatGPT напрямую в GitHub.

## Что внутри

- `index.html` — страница
- `style.css` — оформление
- `script.js` — интерактивный счётчик

## Как запустить в Codespaces

Открой репозиторий в Codespaces и в терминале выполни:

```bash
python3 -m http.server 8000
```

После этого открой порт `8000` во вкладке Ports.
