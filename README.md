# Cosmic Three.js Demo

Учебный проект для проверки совместной работы ChatGPT, GitHub, GitHub Codespaces и GitHub Pages.

Проект прошёл путь от простой HTML/CSS/JavaScript-страницы через CSS-куб и базовую Three.js-сцену к полноценной интерактивной космической композиции с загружаемой 3D-моделью корабля.

## Онлайн-версия

Проект опубликован через GitHub Pages:

**https://mamacita8689-hue.github.io/MyFirstRepa/**

Публикация настроена из ветки `main`, папка `/ (root)`.

## Текущее состояние

Сейчас проект содержит интерактивную космическую 3D-сцену на Three.js:

- большая планета с процедурной текстурой
- светящаяся атмосфера
- кольца планеты
- орбитальный спутник
- звёздное поле из тысяч частиц
- более близкий слой ярких звёзд
- цветная туманность
- пылевой пояс вокруг планеты
- направленный и точечный свет
- мягкое свечение дальнего источника света
- загружаемая 3D-модель космического корабля в формате `.gltf`
- загрузка модели через `GLTFLoader`
- плавное движение корабля по орбите
- автоматическое движение объектов сцены
- управление камерой через `OrbitControls`
- смена цветовой атмосферы сцены
- остановка и запуск движения
- возврат камеры в исходную точку
- адаптация под мобильный экран и размер окна

Большая часть окружения генерируется кодом, а корабль хранится как отдельный 3D-ассет в папке `models/`.

## Технологии

- HTML5
- CSS3
- JavaScript ES Modules
- Three.js `0.186.1`
- OrbitControls
- GLTFLoader
- WebGL
- CanvasTexture
- Points / Sprites / BufferGeometry
- glTF 2.0
- GitHub Codespaces
- GitHub Pages

Three.js подключается через CDN и `importmap`, поэтому проект пока не требует `npm` или сборщика.

## Как работать через GitHub Codespaces

Открой репозиторий в Codespaces и выполни:

```bash
python3 -m http.server 8000
```

После запуска открой порт `8000` во вкладке **Ports**.

Если изменения были внесены в GitHub после открытия Codespace, сначала выполни:

```bash
git pull
```

и обнови страницу браузера.

## GitHub Pages

Для обычного просмотра Codespaces не нужен: опубликованная версия доступна по постоянной ссылке GitHub Pages.

После изменений в ветке `main` GitHub Pages автоматически публикует новую версию сайта.

Если нужно временно остановить публикацию, это можно сделать в:

```text
Settings → Pages
```

и отключить источник публикации. Позже его можно снова включить для `main → / (root)`.

## Управление сценой

- зажать и тянуть мышью — вращать камеру вокруг планеты
- провести пальцем — вращать сцену на сенсорном устройстве
- колесо мыши — приблизить или отдалить камеру
- **Сменить атмосферу** — переключить цветовую палитру космоса
- **Остановить движение / Запустить движение** — управлять анимацией сцены
- **Вернуть камеру** — восстановить исходный ракурс
