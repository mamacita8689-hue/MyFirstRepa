# Three.js GitHub Demo

Небольшой учебный проект для проверки совместной работы ChatGPT, GitHub и GitHub Codespaces.

Проект начинался как простая HTML/CSS/JavaScript-страница, а затем был постепенно переведён на настоящую 3D-сцену с Three.js.

## Текущее состояние

Сейчас проект содержит интерактивную 3D-сцену на Three.js:

- настоящий 3D-куб (`THREE.Mesh`)
- перспективная камера (`PerspectiveCamera`)
- WebGL-рендерер
- освещение сцены
- тени
- пол и вспомогательная сетка
- управление камерой через `OrbitControls`
- вращение сцены мышью или пальцем
- приближение и отдаление
- автоматическое вращение куба
- кнопка запуска/остановки вращения
- смена материала куба
- адаптация рендера под размер окна
- небольшой отдельный тест JavaScript-счётчика

## Технологии

- HTML5
- CSS3
- JavaScript ES Modules
- Three.js `0.186.1`
- OrbitControls
- WebGL
- GitHub Codespaces

Three.js подключается через CDN и `importmap`, поэтому для проекта пока не нужны `npm`, сборщик или отдельная система зависимостей.

## Как запустить в GitHub Codespaces

Открой репозиторий в Codespaces и в терминале выполни:

```bash
python3 -m http.server 8000
```

После запуска:

1. Открой вкладку **Ports**.
2. Найди порт `8000`.
3. Открой ссылку на этот порт в браузере.

Если ChatGPT внёс новые изменения в GitHub, а Codespace уже был открыт, сначала выполни:

```bash
git pull
```

и затем обнови страницу браузера.

## Управление 3D-сценой

- зажать и тянуть мышью — вращать камеру вокруг объекта
- провести пальцем — вращать сцену на сенсорном устройстве
- колесо мыши — приблизить или отдалить камеру
- **Сменить материал** — изменить внешний вид куба
- **Остановить вращение / Запустить вращение** — управлять автоматической анимацией

## Зачем этот проект

Основная цель — постепенно пройти путь от простой веб-страницы к полноценной 3D-сцене, а затем использовать те же принципы для AR-проекта.

План развития:

```text
HTML/CSS demo
    ↓
CSS 3D cube
    ↓
Three.js scene
    ↓
GLB/GLTF model
    ↓
Camera + marker tracking
    ↓
AR scene
```
